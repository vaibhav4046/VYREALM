# VYREALM troubleshooting

- **Local video runtime missing:** In Settings, choose a local folder with 25 GB free and install the Windows runtime. Setup needs internet; generation uses local files afterward. The app starts ComfyUI itself.
- **Provider start is slow:** First start imports private CUDA/Python packages and initializes its database. Startup fails explicitly on timeout; retry preserves installed files.
- **Model/code changed:** Run the Settings integrity check. Changed files block generation. Reinstall into a new folder while retaining old files/configuration; do not edit hashes to hide a mismatch.
- **`PROVIDER_HISTORY_LOST`:** The provider lost a submitted but incomplete stage. Earlier stages remain on disk. A retry never labels unrelated files as generated.
- **`ENGINE_STORE_IN_USE`:** Another engine owns this project folder. Close that instance first. Do not run source and desktop engines against the same data simultaneously.
- **Queued with no competing project visible:** Another VYREALM workspace may hold the per-user GPU lease. Let its job finish or cancel it through its owner.
- **Visual review required:** Inspect the clip/contact sheet and record notes before assembling generated or enhanced footage. Technical validation cannot certify realism, identity or performance.
- **Audio delivery verification failed:** The bounded loudness/peak correction could not meet its target. Adjust layer gain or extreme transient dynamics, then rerender. Sources and PCM masters remain saved.
- **Piper/Whisper unavailable:** Setup installs the CPU voice/transcription models. Uploaded narration and manually edited captions remain usable. Unavailable models must not be reported as having run.
- **Where are narration and captions?** Select the project and open **Audio**. Generate narration with Piper, or select an existing speech recording for **Generate timed captions**. Correct words and timing, set **Include captions in the next render**, then **Save audio & caption edits**. Export the timeline again to apply changes to a new MP4.
- **Caption text is wrong or long:** Whisper can misread words, especially names. Edit the returned text against the recording. Word-timestamp results are split into short pages; original transcript evidence is retained. An unavailable or failed transcription is not a completed caption track. A text correction does not establish that the voice sounds correct.
- **Template shows a plan instead of a finished video:** Templates create a new project and save an editable workflow. They do not generate media or install runtimes. Add the sources listed by the selected template, review the script and ranges, then use the production or timeline export controls.
- **Template plan save failed:** The newly created project is kept. Use **Retry saving this plan** to target the same project and current revision, or **Open saved project**. If the initial creation response was lost, check Dashboard before making another project; automatic creation retry is stopped to avoid duplication.
- **Local automation has no selectable project:** Save an edit containing at least one project-owned image or video clip. A brief or workflow plan without a timeline is not an executable render.
- **Scheduled workflow did not start while the app was closed:** Keep VYREALM open for on-time scheduling. A due saved run can start when the app is reopened with the same project data directory. There is no OS wake-up service. Recovery reconciles saved workflow/job records; an interrupted worker can still require attention.
- **Automation says Project changed or Needs attention:** Open its diagnostic. A changed project revision pauses the workflow to preserve newer edits; save the revised timeline and create a new workflow. A failed or interrupted worker is not assumed to have completed. Completed files remain in the project history.
- **Automation says Ready for your review:** The saved edit was rendered, the actual file checked, and creator materials prepared. This is the `needs-review` stopping point. Inspect picture, sound and captions; nothing has been automatically approved or published.
- **MCP connection failed:** Keep the local app running. In **MCP tools**, copy the current configuration and choose **Test local bridge**. The check starts the stdio process and verifies initialization, tool discovery and a read-only project listing. If the app moved or its port changed, replace the old executable/script/API paths in the client configuration. A bridge pass does not prove a separate assistant client is configured.
- **Disk is low:** Edit at 720p or 1080p and retain a backup of originals before removing unused intermediate files. A larger export canvas does not demonstrate higher-detail source generation.
- **Portable JSON limit:** Each asset must be at most 50 MB and total media at most 300 MB. Larger exports are refused; original project/job folders remain intact. Incomplete imports are rejected instead of dropping footage or audio.
- **Installed version differs from these controls:** Windows 1.0.7 has actual NSIS installation and native UI export/download evidence in `work/installed-1.0.7-native-proof/installed-evidence.json`; 1.0.8 installation is pending. Check the version and features of the app actually launched. Source changes and packaging output do not qualify a newer installation; do not bypass OS signing protections.
- **Platform or model capability differs:** macOS has separate qualification requirements. Lip-sync and multilingual dubbing are not connected to the local narration workflow. A file's frame rate or resolution does not prove native generation at that specification.
- **Earth after dark is absent from a source checkout:** Its creative media and project are excluded from the lean source distribution. It is an original VYREALM edit of credited NASA ISS footage with local Piper narration, Whisper captions and FFmpeg assembly; the visuals are not AI-generated. See the README's source links and the development workspace's `work/earth-selected-proof/evidence.json` for the exact file's later visual/technical review and local catalogue selection. `work/quality-short-review/evidence.json` retains its production evidence. Neither record claims subjective audio review.
- **YouTube connection versus upload:** Live Desktop OAuth, channel and analytics readback, and protected Windows token persistence have been tested. No upload or publication has occurred. Each local user connects their own channel; source and project exports contain no account credentials. The configured unverified Google API project and the adapter's private-only policy do not permit claiming public publishing is ready.
