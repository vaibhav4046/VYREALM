Privacy policy

This policy explains the standard local VYREALM application and its optional Google/YouTube connection.

Who provides the app

VYREALM is an open-source project maintained by the contributors to vaibhav4046/VYREALM. For privacy questions, use GitHub support without including sensitive information. Maintainers do not have remote access to your local project library through the standard app.

Data stored on your computer

Projects, prompts, revisions, imported or copied media, transcripts, generated audio, renders, job records and receipts are stored in local files and SQLite. The desktop app uses the current operating-system user's application-data directory; source runs normally use the configured local data directory. Copies and backups you make are separate. Local logs can contain operational details and file paths.

Optional Google data access

With your consent and a configured OAuth client, the integration requests permissions needed for YouTube channel readback, upload and/or read-only analytics. It uses channel identifiers and names to show and confirm the destination account, analytics reports to answer your requested channel queries, and video bytes, titles, descriptions and tags to perform an upload you confirm. It does not request your Google password.

OAuth access and refresh tokens are stored in the local protected credential vault. On the supported Windows route, DPAPI protects the vault's encryption key for the OS user. Channel state and operation receipts may be retained locally. A stored token is not a guarantee that Google still authorizes access.

Sharing and processing

Local editing does not send your project library to VYREALM maintainers. When you authorize or use Google features, Google receives authorization requests, requested API queries and, for a confirmed upload, the selected video and metadata. Google processes that information under its Privacy Policy. VYREALM does not sell Google user data or use it for advertising or general-purpose model training. Google data is used to provide the features you request, not to build advertising profiles.

Optional research sends requests to the public sources you choose. Model setup may contact model and package hosts. Configured external tools/providers follow their own policies; cloud inference is not enabled by default. This public information site has no added analytics, ad scripts or forms. GitHub Pages hosts it and may process routine request information under GitHub's privacy statement.

Disconnect, revoke and delete

Use the app's YouTube disconnect control to remove locally stored OAuth tokens and cached connection state. Disconnecting locally does not revoke Google's account-level grant, remove uploaded videos, or erase project/job history. To revoke access, use Google Account third-party connections. Manage or delete uploaded videos in YouTube Studio.

Local project data remains until you remove it. Back up any wanted files, stop the app, and remove the relevant configured local data files if you want to erase the local library; uninstalling the program alone may leave user data. Use available in-app deletion controls where provided, but do not assume they securely erase original source files, exported copies, backups or historical receipts. VYREALM does not operate a server copy of your local library that maintainers can delete for you.

Retention, security and changes

The standard local app has no automatic retention deadline for projects and receipts. Google retains data according to its services and your account settings. Protect your OS account and backups; no storage system offers absolute security. This policy will be updated when data handling changes, with the date shown above.
